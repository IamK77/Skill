# Shared meaning across different rendering media

## An opening

Imagine a selected direction expressed on a web page, an interactive canvas, and a static report. Which semantic relationships should travel between media, and which implementation values should differ? Shared tokens can express a common idea without forcing different renderers into identical mechanics.

## Elaborate a candidate

Distinguish semantic roles from platform-specific output values. Choose an authoritative editable source or a validated mapping, keep derived outputs reproducible, and inspect actual consumers after changes. A shared role need not imply mechanically identical pixels across CSS, canvas, charts, and static documents.

## A small comparison

A status colour can carry the same meaning across a form and a chart while requiring different accompanying labels, line styles, or output formats. Test those relationships and keep intentional differences explicit rather than creating parallel undocumented palettes.
