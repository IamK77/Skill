# A thin slice through real integration seams

## Input

Start with one chosen journey and an observable acceptance example. Name the browser action, route, service call, persistence effect, and visible response that the slice needs to connect.

## Method

Implement the smallest path that crosses the uncertain seams. Use real contracts where possible. If a service is unavailable, keep the substitute contract-faithful and label the integration as unverified rather than claiming that a mock response proves connectivity.

## Example

A save-preferences slice should demonstrate that a changed value reaches the intended service and survives a reload through the retrieval path. A component toggling its own local variable only proves local interaction.

## Branches

If the journey itself is undecided, clarify it or explore alternatives with bearings. If the question is ordinary CSS mechanics, answer it directly rather than building a skeleton. Do not expand a seam experiment into the whole product.

## Result

Leave reproducible setup, a recorded successful journey, a meaningful failure example, and the unresolved seam list. The current keel SOP records completion; this note adds technique, not another stage.
