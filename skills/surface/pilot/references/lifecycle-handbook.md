# Optional handoffs, not a pipeline

- bearings → a selected journey → keel.
- wellspring → a selected state model → keel or trials.
- livery or an atelier lens → a selected visual direction → atelier systems.
- keel → a running thin slice → seaworthy or trials.
- systems → tokens/component contracts → bulwark.
- a release request → observation needs → lookout.

Begin where the actual task begins. No upstream certificate is required. A creative conversation may end with an open question rather than a handoff.
