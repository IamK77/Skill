# Choose a small representation experiment

## An opening

Treat the decision tree as a collection of routes to try. Start with a concrete awkward example and change its representation, ownership, or time model. Do not classify every line of code before exploring an alternative; a tiny counterexample can be more generative than a complete taxonomy.

## Elaborate a candidate

Start from one awkward example, not a comprehensive smell inventory. Ask whether changing a value shape, event model, ownership boundary, or interface would make the example easier to explain. Use familiar patterns as available constructions rather than a mandatory vocabulary test.

## A small comparison

Several booleans can describe a genuinely independent set of conditions, or accidentally encode contradictory states. Try a discriminated representation on one relevant interaction and compare what it excludes. Keep the existing form if the experiment does not clarify the actual behaviour.

## Keep the choice open

Use this note when its question is useful, not as a required inspection. A sketch, a contrast, or an unresolved question can be the result. The [parent lens](../SKILL.md) offers other ways into the subject; execution begins only when a direction and task are chosen.
