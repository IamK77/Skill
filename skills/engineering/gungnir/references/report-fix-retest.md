# Produce a reproducible finding and verify its repair

## Use when

Use the demonstrated path, target revision, prerequisites, agreed disclosure channel, and proposed repair.

## Method

Write concise reproduction steps with expected versus observed behaviour and evidence that supports the stated impact. Locate the responsible boundary and propose a regression that distinguishes the old and repaired behaviour. Retest both the permitted path and the rejected misuse after the change, including relevant alternate entrypoints or issued capabilities.

## Example and record

An ownership repair should reject a second principal's request while preserving the legitimate operation. If previously generated download links remain usable, name that residual issue rather than presenting the handler fix as complete revocation.

## Limits and handoff

Separate confirmed impact, inference, mitigation, and untested conditions. A prepared report is not permission to submit it, contact a third party, or publish details.
