# Working with colour coordinates

## An opening

Keep one accent fixed and change the surrounding neutrals: untinted, warm, cool, then nearly the same hue. Notice which version makes the accent seem embedded in a material and which makes it seem like a signal. A neutral ramp can express a relationship without pretending that tinted grey is inherently more sophisticated.

## Elaborate a candidate

Separate the role a colour serves from the coordinates used to express it. Perceptual colour spaces can make some relationships easier to manipulate, but gamut limits, display conditions, and the rendered neighbours still matter. For a neutral family, compare several plausible temperatures at the same semantic roles instead of assuming every neutral must carry a tint.

## A small comparison

Apply each family to a real paragraph, a selected control, and a large surface. Inspect state distinctions and measure the required foreground/background combinations. Retain the values for the candidate being developed, not a universal recipe for all products.

## Keep the choice open

Use this note when its question is useful, not as a required inspection. A sketch, a contrast, or an unresolved question can be the result. The [parent lens](../SKILL.md) offers other ways into the subject; execution begins only when a direction and task are chosen.
