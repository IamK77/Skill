# Hand off a selected visual direction as inspectable artifacts

## Use when

Use the chosen direction, real component use cases, target platforms, and decision owners.

## Method

Translate selected relationships into named tokens, representative components, and examples with actual content. Record semantic intent, important states, themes, and intentional exceptions. Identify which values are implementation details and which are shared contracts. Review the rendered consumer, not only a design-file export, and keep unresolved decisions visible.

## Example and record

A selected emphasis colour becomes a semantic role with tested foreground/background combinations, not a hexadecimal value copied independently into every component. Include a disabled or error state where it affects the contract, and document a deliberate exception rather than hiding it in an override.

## Limits and handoff

A small product may need one token file and a few examples rather than an elaborate platform. The handoff implements a chosen direction; it does not retroactively require a creative certificate or a complete inventory of every possible component.
