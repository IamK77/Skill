# Reusable spacing with room for meaning

## An opening

Try a page as a compact working notebook, a measured editorial spread, and a sparse set of annotations. Preserve the words while changing the rhythm between them. A scale can make a chosen rhythm reusable, but meaningful grouping sometimes needs an intentional exception.

## Elaborate a candidate

Define a small useful vocabulary for the chosen design's recurring gaps, padding, and grouping. Relate those values to actual type and content rather than choosing a numerical base as an aesthetic guarantee. Distinguish internal component spacing from spacing that communicates a relationship between groups.

## A small comparison

Apply the candidate vocabulary to a dense form and an editorial passage. If the same token obscures a meaningful grouping, revise the role or allow an intentional exception. The goal is an understandable rhythm, not the maximum percentage of values that fit one scale.
