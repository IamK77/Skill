# Familiar visual patterns as creative prompts

## What the probe can observe

The optional canon probe reports declared surface indicators such as a cool dark canvas, a familiar accent band, a framework palette value, certain typography and layout patterns, gradient effects, and some repeated copy structures. Those names are implementation categories in the probe, not a model of authorship or aesthetic merit. A human can choose those forms deliberately; a generated design can avoid every indicator and still be uninteresting.

## Change a relationship rather than chase a score

If a centred hero appears, imagine the same product as an annotated field report or a conversation already in progress. If a blurred panel appears, ask whether translucency expresses layering, privacy, or simply an attractive material. Keep the form if it suits the idea. There is no obligation to explain every flag away.

## Example

A scientific instrument can use a dark canvas and luminous accent to make selected observations prominent. Replacing that palette with cream and serif type merely to avoid a detector would not necessarily improve it. A more interesting alternative might change the subject from live measurement to accumulated field notes, which changes composition and content as well as colour.

## Interpretation limits

A zero count means only that the implemented indicators did not fire on the inspected rendering. It does not measure originality, coherence, accessibility, or user value. Inspect the actual output and coverage when a flag is surprising. Use [probe instructions](../probes/README.md) for execution, not as a creative prerequisite.

The other canon notes offer ways to invent a direction without running any probe.
