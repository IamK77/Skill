# Structure attention, not only alignment

## An opening

Arrange the same information as a timeline, a shelf, a constellation, and a conversation. Each makes different relationships visible. A grid can support one of these ideas, but regularity itself need not be the subject or the final measure of the composition.

## Elaborate a candidate

Choose the relationships to foreground: sequence, comparison, grouping, priority, or spatial association. A grid can make those relationships repeatable, while an intentional break can establish emphasis. Check the reading path with actual content and several states; equal-sized containers need not imply equal importance.

## A small comparison

Arrange a project overview as an inventory and as a timeline using the same items. Ask what a reader notices or can compare in each. The result may suggest a different information model rather than a new number of columns.

## Keep the choice open

Use this note when its question is useful, not as a required inspection. A sketch, a contrast, or an unresolved question can be the result. The [parent lens](../SKILL.md) offers other ways into the subject; execution begins only when a direction and task are chosen.
