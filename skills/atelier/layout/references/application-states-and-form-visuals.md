# Compose around incomplete and changing work

## An opening

Let an unfinished or interrupted state lead the composition. An empty result can invite a question; a failed submission can retain a visible draft; a long operation can become a revisitable artifact. These are different proposals for the experience, not just placeholders added around a completed screen.

## Elaborate a candidate

Use the actual meaning of each state rather than a universal set of decorative placeholders. An empty collection, a first-time visit, a loading refresh, an invalid draft, and a failed submission can call for different information and actions. Layout can preserve continuity or expose a new choice without implying that every state needs a separate panel.

## A small comparison

Sketch the same form while editing, while a submission is unresolved, and after a recoverable failure. Keep relevant input and the next useful action visible. This can generate the interaction's composition before detailed state handling becomes an implementation task.

## Keep the choice open

Use this note when its question is useful, not as a required inspection. A sketch, a contrast, or an unresolved question can be the result. The [parent lens](../SKILL.md) offers other ways into the subject; execution begins only when a direction and task are chosen.
