# Search around the actual missing capability

## Use when

Use the desired behaviour, ecosystem vocabulary, known neighbouring projects, and constraints.

## Method

Try the capability's user-facing term, its implementation mechanism, a relevant interface or file format, and vocabulary from neighbouring domains. Record useful queries and the surfaces consulted. Check the current search surface's syntax instead of assuming one provider's operators work everywhere. Follow a promising dependency or integration link when it exposes a concrete candidate.

## Example and record

A need described as offline collaboration may lead through replicated data types, document synchronisation, local-first storage, or conflict resolution. These are leads to inspect, not interchangeable implementations of the same requirement.

## Limits and handoff

Do not turn query count into a success metric. Stop at the agreed budget or sufficient useful candidates, and distinguish current observed support from an inferred possibility.

Use the [current skill workflow](../SKILL.md) for the selected task and its completion conditions. This reference adds technique, not a separate run or mandatory stage.
