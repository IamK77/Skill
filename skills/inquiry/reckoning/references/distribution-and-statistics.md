# Inspect the population behind an aggregate

## Use when

Use the plan, raw run manifest, metric definitions, and the population the claim concerns.

## Method

Account for included, excluded, missing, and failed observations before summarising. Inspect distributions, meaningful subgroups, resource tradeoffs, and pairing or dependence. Report effect size and uncertainty using a method appropriate to the design. Preserve the analysis code and identify planned versus exploratory comparisons.

## Example and record

An average improvement may conceal a severe regression on one instance family. Show that regime and determine whether the claim should be narrowed. Repeated measurements of the same underlying instance should not silently become independent evidence about a broader population.

## Limits and handoff

A chart or significance result cannot fix a compromised data boundary. If assumptions are uncertain, report the limitation or obtain statistical review; do not select a favourable analysis only because it yields a desired verdict.
