# Write the narrow conclusion supported by the record

## Use when

Use the experimental plan, complete run accounting, analysis, and proposed claim set.

## Method

Separate observations, interpretations, and implications. Look for the strongest counterevidence and the conditions under which the result changes. Link each material statement to an artifact or source and identify unresolved uncertainty. A null or negative result is a legitimate outcome when the experiment addresses its question.

## Example and record

A method can improve mean performance while using more resources and failing on a meaningful subgroup. A useful conclusion states those tradeoffs instead of celebrating one metric or discarding the work entirely.

## Limits and handoff

Critical analysis is not a demand to reject every result, and a favourable result is not inherently suspicious. The objective is a bounded, inspectable claim that another person can evaluate, not a compulsory approval ceremony.
