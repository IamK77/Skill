# Design informative comparisons within a real budget

## Use when

Use a selected hypothesis, proposed mechanism, available compute/data, and the decision the experiment should inform.

## Method

Choose component removals or substitutions that distinguish plausible explanations, then identify parameters or conditions whose variation could change the conclusion. Record comparable data and compute treatment, repetitions, stopping conditions, and resource limits. Separate feasibility work from the committed comparison and document changes to the plan.

## Example and record

If a hybrid method improves quality, compare removing its memory component and substituting its proposal mechanism while recording the resource differences. A smaller model using less compute is not automatically an isolated test of one mechanism. Retain configurations and the rationale for each comparison.

## Limits and handoff

No fixed number of ablations proves a mechanism or a paper's worth. Avoid an exhaustive grid when a smaller discriminating experiment answers the question, and do not spend beyond the authorised budget.
