# Specify what will be measured and compared

## Use when

Use the research question, unit of observation, outcome distribution, and intended decision.

## Method

Define metric computation, aggregation, missing/failed-run handling, and relevant resource measurements. Choose an uncertainty or comparison method that matches dependence, pairing, sampling, and distribution assumptions. Record multiplicity and exploratory analyses where they affect interpretation. Use effect magnitude and practical meaning alongside any significance decision.

## Example and record

Repeated seeds on the same instance are not automatically independent samples from the deployment population. Keep instance-level variation and run-level variation distinguishable, and specify which level the inference concerns. Retain the analysis code and input manifest.

## Limits and handoff

Do not prescribe one test or p-value threshold for every design. If the assumptions or inference are consequential and unclear, obtain appropriate statistical review instead of attaching a familiar test name to an unsuitable analysis.
