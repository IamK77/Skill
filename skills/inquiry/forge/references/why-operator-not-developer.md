# Execute a plan without hiding methodological changes

## Use when

Use a selected experimental plan and an authorised execution budget.

## Method

Implement and run the planned comparison while preserving its identity and boundaries. Distinguish engineering repairs that restore the intended procedure from methodological changes that alter the question, population, or comparison. Record the latter as plan revisions and obtain the relevant decision before treating their outputs as the original experiment.

## Example and record

Fixing a logger may preserve the comparison; changing a baseline's search budget changes it. A faster implementation may also alter numerical or resource behaviour worth checking. Keep those consequences explicit instead of classifying every code edit as harmless execution detail.

## Limits and handoff

The operator/developer distinction is a division of responsibility, not a read-only guarantee or a prohibition on needed implementation work. Tool permissions and environment controls remain separate from the written role.
